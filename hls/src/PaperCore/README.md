# PaperCore support modules

These 14 modules are part of this HLS package. They provide buffer/access analysis, index sequences, SMT support and their semantic dependencies. The direct entry modules are `PaperCore.WindowAnalysis` and `PaperCore.IndexSequenceSMT`.

Names and proof bodies are preserved from the paper-AST implementation. No sibling PaperCore package or standalone paper compiler is required. Build from the HLS directory with `lake build IRComparison IRComparison.Tests`.
